一、为什么“背景能动，但没有按钮 / 点不动”——排查步骤

  1. 看层级：背景动画对象的 Canvas/Sprite 是否盖在 Button 之上？——Hierarchy 里把 Button 拖到最下（=渲染最上），或 Canvas 里 UI 应在 Canvas > Layer 0，背景在 Camera > Sprite。
  2. 看射线拦截：选中背景 Image/Animation 节点 → Unity: 取消勾选 Raycast Target；Godot: mouse_filter = IGNORE；Canvas: pointer-events:none。90% 的“点不动”是这个。
  3. 看有没有渲染出来：按钮 alpha=0、scale=0、被动画停在第 0 帧？先用 Button.gameObject.activeInHierarchy / visible 打日志确认。
  4. 看异步流程：加载存档/音效的 await 抛异常 → 后续 ShowMainUI() 没被执行。用 try/catch/finally 或 Promise.race(timeout) 保证 UI 一定渲染。
  5. 看场景切换：“开始”按钮的 onClick 是否绑了？事件系统是否存在（场景里要有 EventSystem / Control）？
  6. 看 Canvas Scaler：不同分辨率下按钮被挤出屏幕——设 Scale With Screen Size (1280x720) + anchoring 居中。
  7. 最小复现：新建空场景只放“背景+一个按钮”，能点 = 原场景是遮挡/时序问题；不能点 = EventSystem/层级问题。

二、通用原则（本页已实现）

  • ① 交互层 z-index:9999 置顶，背景 pointer-events:none（关闭 RaycastTarget）。
  • ② 资源加载无论成败，finally 中强制渲染“开始游戏”按钮，超时 3 秒视为失败也渲染。
  • ③ “开始”直接同步切屏到种族选择 → 地图选择，无过场动画依赖。

四、Godot 4 修复代码（GDScript）

home_ui.gd
extends Control

@onready var home   = %HomePanel
@onready var race   = %RacePanel
@onready var map    = %MapPanel
@onready var bg     = $BackgroundAnim   # Sprite2D / TextureRect
@onready var btn    = %BtnStart

func _ready() -> void:
    # 关键1：背景不接收鼠标 + UI 顶层
    if bg is TextureRect: bg.mouse_filter = Control.MOUSE_FILTER_IGNORE
    elif bg is Node2D:    bg.mouse_filter = Control.MOUSE_FILTER_IGNORE
    z_index = 100
    # 关键2：兜底渲染开始按钮（3 秒超时也不拦 UI）
    btn.visible = false
    var ok = await _load_with_timeout(3.0)
    btn.visible = true            # 无论成败都显示
    if not ok: push_warning("资源加载失败，使用兜底 UI")
    btn.pressed.connect(enter_race_select)   # 关键3

func _load_with_timeout(t: float) -> bool:
    var task = _load_save_async()            # 你的异步加载
    var timer = 0.0
    while not task.is_completed() and timer < t:
        timer += get_process_delta_time()
        await get_tree().process_frame
    return task.is_completed()

func enter_race_select() -> void:
    home.visible = false
    race.visible = true      # 人/夜/兽/鬼
func enter_map_select() -> void:
    race.visible = false
    map.visible = true       # 地图选择

// 关键1：交互层置顶，背景关闭射线拦截
bgLayer.style.pointerEvents = 'none';   // = raycastTarget=false
uiLayer.style.zIndex = 9999;

// 关键2：异步容错 —— 超时/失败也强制渲染开始按钮
async function boot() {
  const btn = document.getElementById('btn-start');
  try {
    await Promise.race([
      Promise.all([loadData(), loadAudio()]),   // 真实加载
      new Promise((_, rej) => setTimeout(() => rej(new Error('timeout')), 3000)),
    ]);
  } catch (e) {
    document.getElementById('start-fallback-note').style.display = 'block';
  } finally {
    btn.style.display = 'inline-block';        // 兜底：一定显示
  }
}
boot();
